# Images

## Project icon

[csl-ai4eda-emblem.png](csl-ai4eda-emblem.png) is the CSL_AI4EDA project emblem: a microchip containing a security shield and connected AI nodes, with a small interlocking plugin module. Its ink illustration style uses deep navy outlines with muted blue, teal, sage and warm gold to coordinate with the overview. Both homepages display it above the project title at 144 pixels wide, preserving its proportions and transparent background. It was created with the built-in image generation tool using the maintainer's style reference and the project overview as palette guidance. It is separate from the laboratory and university identity images in the contact section.

## Homepage navigation buttons

The five `button-*.svg` images in [icons/](icons/) retain the compact Shields badge style, with muted blue, teal, sage, warm gold and blue-gray accents coordinated with the overview. The three primary links use the 28-pixel-high `for-the-badge` style; the two secondary links use the 20-pixel-high `flat-square` style with a gray label segment. The SVGs are stored locally, contain no external resources and retain the existing README link destinations.

## Overview illustration

[overview-plugins-color-icons.en.png](overview-plugins-color-icons.en.png) is the English overview used by both CSL_AI4EDA homepages. It uses a white background, muted blue, teal, sage and amber cards, and small matching icons: magnifying glass, gear, code document and speech bubble.

The plugin order is Security Detection, Optimization & Repair, Secure Generation, then HDL Copilot. A trailing ellipsis indicates additional plugins in development. The illustration was created with the built-in image generation tool and checked for labels and order.

The earlier [minimal overview](overview-plugins-minimal.en.png) is retained as a previous version.

## Homepage heading icons

The four SVGs in [icons/](icons/) are small, locally stored line icons for the plugin headings. They match the overview's magnifying glass, gear, code document and speech bubble, using the same blue, teal, sage and amber accents. Both homepages render them at 24 × 24 pixels. The six main section headings use a single emoji each; existing section links retain named anchors.

## Plugin interface previews

The four GIFs in [demos/](demos/) use the original published plugin interfaces with built-in demo or sample data. Each is 960 × 750 pixels and loops every 12 seconds. Camera zoom, focus boxes and background dimming guide attention without replacing the interface. The optimization preview retains its unverified candidate status; these animations do not report a new end-to-end validation run.
