# Security Detection Plugin

**Locate RTL vulnerabilities and analyze module-access permissions.**

[Home](../../README.md) · [Plugin directory](../README.md) · [Framework](../../docs/ARCHITECTURE.md)

The Security Detection Plugin groups RTL vulnerability detection and multi-module access-control analysis. Its technical context is **VerilogLAVD (CWE) + multi-module access checks**.

## Scope

- RTL vulnerability locations and relevant code context.
- Multi-module permissions and access-control relationships.
- Analysis results that help an engineer inspect a finding and decide on subsequent validation or repair.

## Documentation entry

This first publication records the plugin's scope and its place in the design flow. Installation, supported inputs, executable usage and validation details will accompany the implementation release. This directory contains documentation only.
