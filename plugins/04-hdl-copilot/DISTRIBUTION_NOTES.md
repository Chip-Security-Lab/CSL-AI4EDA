# Distribution and licensing notes

Public documentation uses HDL Copilot Plugin; installed names, extension ID `trustrtl-local.trustrtl`, and `trustrtl.*` settings retain compatibility.

The tested VS Code 0.4.0 package is copied byte for byte. The unchanged Vivado companion and independent examples ZIP are carried forward. The repository provides bilingual guides for the new sidebar and editor settings, plus a layout preview that uses simulated answers and statistics.

The VSIX includes readable JavaScript and Python; the Vivado ZIP contains readable Python, JavaScript and Tcl. Package distribution does not conceal implementation. Development datasets, caches, test artifacts, actual model credentials and conversation histories are excluded from the repository content.

No standalone LICENSE or third-party notice was found in the supplied runtime archives. Maintainers still need to confirm distribution terms for the implementation and examples. This preparation does not grant a new license or apply another plugin's license to this component.
