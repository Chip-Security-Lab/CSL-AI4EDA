# HDL Copilot Plugin 使用说明

**CSL_HDLChat 是面向 RTL 工程师的 VS Code 助手，通过精简多轮问答与可审查的代码修改，帮助理解、排查和改进 Verilog/SystemVerilog。**

当前版本：**v0.3.4**。支持中文和英文界面。

[English user guide](USER_GUIDE.md) · [插件介绍](README.zh-CN.md) · [示例总入口](examples/README.md)

## 1. 安装环境与依赖需求清单

### 1.1 环境要求

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | 当前以本地 Windows 为验证环境 | macOS、Linux 和 Remote SSH 尚未完成验收 |
| VS Code | 1.85.0 或更高版本 | 使用桌面版 VS Code |
| Python | 3.10 或更高版本 | 插件自动启动本地 Python 后端 |
| 插件安装包 | `CSL_HDLChat-0.3.4.vsix` | 从 VSIX 文件安装 |
| 模型服务 | 兼容 Chat Completions API | 准备 API 基础地址、模型名称和 API Key；无需鉴权的本地服务可不填密钥 |
| 网络 | 能访问所配置的模型服务 | 使用云端模型时需要对应服务的网络访问权限 |
| 工作区 | 打开并信任自己的工程文件夹 | 受限模式下插件不可用 |

安装包已包含问答后端代码，运行时使用 Python 标准库，**不需要额外执行 `pip install`**。普通使用不需要安装 Node.js、npm、AutoGen、OpenAI SDK、Vivado 或 MCP 服务，也不需要 GitHub Copilot 账号。

### 1.2 安装前检查

- [ ] 已安装 VS Code 1.85.0 或以上版本。
- [ ] 已安装 Python 3.10 或以上版本。
- [ ] 已准备插件 VSIX 安装包。
- [ ] 已准备可用的模型地址、模型名称和密钥。
- [ ] 已准备 RTL 文件，或者计划使用内置演示。

在终端检查 Python：

```powershell
python --version
```

如果找不到 `python`，或其版本低于 3.10，在 VS Code 设置中搜索 `trustrtl.pythonPath`，填写已安装的 Python 3.10+ 可执行文件路径，例如：

```text
C:\Python311\python.exe
```

上面的路径仅为示例，应替换成自己电脑上的实际路径。

### 1.3 安装插件

1. 打开 VS Code，按 `Ctrl+Shift+P`。
2. 输入并选择 **Extensions: Install from VSIX...**（扩展：从 VSIX 安装）。
3. 选择 `CSL_HDLChat-0.3.4.vsix`，等待安装完成。
4. 如果 VS Code 提示重载窗口，点击重载。
5. 打开自己的工程文件夹，在确认可信后启用工作区信任。
6. 点击左侧活动栏的 **C 图标**，进入 CSL_HDLChat。

也可以通过命令面板运行 **CSL_HDLChat: 打开聊天**，英文界面对应 **CSL_HDLChat: Open Chat**。

插件保留 `trustrtl-local.trustrtl` 扩展标识和 `trustrtl.*` 设置名，便于升级原 TrustRTL / CSL_HDLChat，继续使用已有配置和工作区会话。

## 2. 简单使用教程

首次打开会自动显示四步使用引导，依次介绍模型设置、顶部输入区、回答区和演示入口。完成或跳过后不再自动显示；点击顶部“使用引导”可随时重看。

### 2.1 配置模型

点击 **模型设置**，在同一个表单中填写以下三项，然后点击 **保存设置**。

| 字段 | 填写内容 | 示例或注意事项 |
| --- | --- | --- |
| API 基础地址 | 模型服务商提供的基础 URL | 例如 `https://api.example.com/v1`，这是格式示例，不是可用服务；不要填写完整的 `/chat/completions` 接口路径 |
| 模型名称 | 服务商实际支持的模型 ID | 使用服务商提供的准确名称，不要填写自定义昵称 |
| API Key | 与该服务对应的密钥 | 直接粘贴，不加引号；首次使用需要鉴权的服务时必须填写 |

已有密钥时，留空表示保留；输入 `-` 表示清除密钥，适用于无需鉴权的本地服务。密钥保存在 VS Code SecretStorage 中，不写入工程文件或会话记录。

保存设置不等于连接测试成功；发送第一条问题后可确认模型是否可用。提问时，问题、关联的当前文件和会话上下文会发送到这里配置的模型服务。

### 2.2 提问与查看回答

1. 打开一个 `.v`、`.sv`、`.vh` 或 `.svh` 文件。
2. 确认插件顶部的“当前文件”显示要分析的文件。
3. 在顶部输入框描述问题、预期行为和约束，例如：

   > 请检查当前计数器是否每 10 拍回到 0，保留端口和复位方式，并给出最小修改建议。

4. 点击 **发送**，也可以按 `Ctrl+Enter`（macOS 为 `Cmd+Enter`）。
5. 在输入框下方查看处理进度和回答。

每轮会读取当前文件的最新内容，包括尚未保存的编辑。没有关联文件时，也可以直接询问概念问题或粘贴 RTL 代码。若只想讨论粘贴的代码，请先确认当前文件提示为“未关联文件”。

阶段显示依次为 **M1 理解需求 → M2 生成草稿 → M3 核心筛选 → M4 精简回答**。回答支持重点文字高亮、独立代码块和复制代码，并展示精简字符数等统计；这些统计不代表代码正确性验证。

可以在同一会话继续追问；点击 **新会话** 开始新的讨论，点击 **历史** 恢复之前的工作区会话。点击 **停止** 可结束本地等待，远端模型服务可能仍在处理已发送的请求。

### 2.3 预览并应用修改

1. 完成当前文件的问答分析。
2. 点击 **生成修改方案并预览**。
3. 在 VS Code 差异视图中比较原文件和建议内容。
4. 确认后点击 **应用修改**，插件才会更新编辑器。
5. 检查结果后自行保存；需要恢复时使用撤销。

应用修改不会自动保存到磁盘。文件在分析后被编辑或切换时，需要重新分析。纯粘贴代码的问答不能直接应用到工程文件；请先打开目标文件并重新分析。

### 2.4 使用演示与切换语言

点击 **演示**，可以选择以下案例：

| 演示 | 体验内容 |
| --- | --- |
| 计数器边界 | 定位模 10 计数器的边界错误，预览并手动应用修改 |
| 组合逻辑锁存器 | 分析缺少默认赋值导致的锁存器推断 |
| 非阻塞赋值流水线 | 逐拍解释寄存器和加法结果的数据时序 |

演示会打开一个新的未保存文件并填入问题，不会覆盖工程文件。点击发送后才调用已配置的模型。

在聊天顶部选择 **中文 / English** 即可切换界面，选择会自动保存。已有回答、草稿和 RTL 代码不会被翻译；需要英文回答时，请用英文提问或明确要求英文回答。命令面板中的命令名称跟随 VS Code 自身的显示语言。

### 2.5 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 找不到插件入口 | 从命令面板运行“CSL_HDLChat: 打开聊天”；确认安装后已重载窗口 |
| Python 后端未启动 | 检查 `python --version` 和 `trustrtl.pythonPath`，再运行“CSL_HDLChat: 重启后端” |
| 模型请求失败 | 检查 API 基础地址、模型名称、密钥及网络；确认密钥对应当前服务 |
| 无法应用修改 | 先分析当前文件并预览差异；文件已变化时重新分析 |
| 会话超过容量 | 新建会话，提供当前代码和必要的设计约束 |

当前版本一次分析一个文件，文件上限为 60,000 字符，会话上下文上限为 80,000 字符。插件只提供问答和修改建议，不自动执行编译、仿真、综合或 PPA 优化；修改后的 RTL 应通过自己的验证流程检查。


## 3. Vivado 配套界面

1. 解压 `CSL_HDLChat-for-Vivado.zip`，保留完整的 `HDLChat-for-Vivado` 目录。使用 Project Mode 工程、Python 3.10+ 和已保存的 RTL；可选模式面板需要 Tkinter。
2. 在 Vivado Tcl Console 中 source 实际安装路径下的 `HDLChat-for-Vivado/tcl/hdlchat.tcl`，再执行 `hdlchat::open`。有空格的路径放在花括号中。
3. 也可用 **CSL_HDLChat: Choose Mode** 工具栏按钮、`hdlchat::launch`，或者 `hdlchat::ask {问题}` 命令行入口。
4. 在配套界面中配置自己的模型地址、名称和密钥。配置保存在服务进程内存中，重启 Vivado 或后端后需重新填写。
5. 确认工程和已保存文件。默认跟随 Sources 选择，手动固定后停止跟随；每轮重新确认上下文，会话按工程隔离。
6. 查看回答与修改差异后，手动复制到编辑器检查并保存。此接口没有写回工程的接口，只读取磁盘内容；提问前先保存文件。

可在启动 Vivado 前用 `HDLCHAT_PYTHON` 指定解释器。完整原始快速开始和使用教程已随 Vivado ZIP 保留；[Vivado 示例](examples/vivado/README.md) 也随包提供。该包未单独声明数字版本，本次核对其全部文件仍与最新源快照一致。
