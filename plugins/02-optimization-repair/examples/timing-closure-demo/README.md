# 真实时序闭环回归工程

此工程专用于验证同一 FPGA、同一份 8 ns XDC 下的时序优化闭环。

- `baseline/`：单周期长算术路径，包含长算术路径；是否存在负 WNS 取决于器件、工具与约束，必须实测。
- `candidate/`：将同一轮函数拆分为四个顺序阶段，历史流水线验证夹具，不是当前单模块插件自动生成的候选。
- 两个版本使用相同顶层端口、同一份 XDC 和相同测试向量。
- 候选增加每轮的延迟，总延迟由 4 个处理周期变为 16 个；该变化仅在
  `timing_contract.json` 明确允许的 `max_added_cycles: 12` 范围内有效。

该样例用于测试 RTL、功能黄金模型与显式变延迟契约，时序结论须以实际 Vivado 报告为准，不用于
物理功耗或论文基准结论。
