# 线上模型能力测试输入

这些是专门覆盖类型与变换前提的合成 RTL，不是 AES 或安全密码核，也不证明任意用户 RTL 都能修复。原 type-expansion 样例和未改善记录保留，不改写为成功。

- T03 改为真正持有秘密数据的条件寄存器更新；原样例只有结构风险、没有显著敏感热点。
- T02 单比特非线性 AND，两个已编码输入和独立新鲜随机位是 ISW 实验的前提。原始结构含两级寄存；候选不能减少或增加可见周期。
- T08 位宽严格为 4，模 16；可匹配 Goubin B2A4 的函数适配器。输出高四位必须保持为零。
- T09 在下降沿捕获秘密门控使能。这个前提使 gated-clock 到数据使能改写有可能保持边沿行为；原始任意秘密门控样例仍可能不可自动修复。
- T10 两个分支分别是 F(plaintext) 和 F(1)，F(x)=(x+3)*5；可尝试把选择放在公共运算之前。RTL 深度风险下降不证明物理延迟安全。

随机输入的均匀性、独立性与新鲜性均为假设。所有候选仍须完整接口、同周期功能、形式及同条件 RTL-TVLA 验证。不得仅靠模型解释、测试电路存在或论文算法名称宣称修复。

每类的可重复测试输入、资源声明和补充要求见 specs.json。线上模型从原始输入生成完整候选；specs 不包含候选代码，不代替任何测量。
