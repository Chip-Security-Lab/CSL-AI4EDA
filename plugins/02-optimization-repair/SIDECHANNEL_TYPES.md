# 侧信道类型支持与证据边界

随 0.5.3 分发的能力说明，整理自包内类型支持文档。

默认自动检查十类，按检测证据、策略与实际资源前提生成候选；无需先判断类型，也无需额外勾选实验开关。新增八类仍保留实验状态和证据限制，不保证任意 RTL 有合法修复。研究规则命中、结构风险、候选生成、验证结果分别记录。

| 类型 | 检测与前提 | 候选生成 | 验证上限 / 当前缺项 |
| --- | --- | --- | --- |
| T01 寄存器翻转 | 现有研究图与 RTL-TVLA | 原规则与模型，默认开放 | 保留原验收门槛；不代表物理安全 |
| T04 地址/查表 | 地址边界与规则匹配 | 原规则与模型，默认开放 | 地址缓解不能当作 T02 非线性修复 |
| T03 秘密控制流 | 研究边界；新增秘密控制的寄存器保持反馈关系 | 实验；条件化双路径/选择改写 | 同周期差分、形式、RTL-TVLA；行为本身泄露时可能无合法改写 |
| T05 过早重组 | 明确份额组；追踪可证的综合别名及 XOR 消费点 | 实验；需已有份额组和公开输出 | 比较重组边界与功能；不证明非线性安全或任意份额编码 |
| T07 掩码复用 | 声明随机输入被多个秘密相关运算消费的结构风险 | 实验；至少两个已有随机输入和逐周期外部新鲜性声明 | 固定伪随机序列下复测；用户声明不证明熵、新鲜性或独立性 |
| T02 非线性替换 | 研究诊断及语义提示与实际非线性门交叉检查，覆盖不完整 | 有条件实验：ISW2 单比特 AND，需已有随机资源及更新声明 | 固定源码哈希、穷举功能/值分布、整文件复验；不代表完整 AES S-box 或毛刺安全 |
| T08 掩码域转换 | 声明布尔/算术域，线性域传播与转换交汇风险 | 有条件实验：Goubin B2A4，严格四位、模 16、已有随机输入 | 只覆盖该 B2A 适配器；不推广到任意宽度/A2B；不证明硬件安全组合 |
| T06 组合毛刺 | 声明同组份额进入非线性组合锥的结构风险 | 实验；只给结构缓解候选 | 最高 RTL 缓解证据，缺门级毛刺/物理证据 |
| T09 秘密时钟 | 秘密污染的寄存器 clock_dep 边界 | 实验；仅在边沿、复位、使能严格等价时 | 增加双边沿及周期内输入/复位扰动差分；形式可能未能证明；最高 RTL 缓解证据 |
| T10 秘密路径 | 秘密选择器两侧结构深度不同的风险 | 实验；并行计算/选择，禁止加流水 | 保留 Yosys 常量分支证据；结构深度不是到达时间；最高 RTL 缓解证据 |

## 使用

正常只需输入 RTL、确认敏感输入、选择模型并生成。基线完成即显示十类检查状态，符合条件的类型继续，缺少资源的类型单独提示。点击“补充信息后重新分析”填写已有随机输入、份额或域；名称建议不是证明，新鲜性声明必须手动确认。通常不使用“高级：限定类型”；专项试验才在其中筛选，新建任务恢复自动。

- 份额分组：每行一组，例如 `state_s0,state_s1`；信号必须能在测量图中唯一解析。
- 随机输入：模块中实际已有的输入，例如 `mask_a,mask_b`。逐周期声明只控制实验刺激与候选前提，不证明真实硬件随机源。不会新增随机端口。
- 公开输出：实际输出端口，例如 `ciphertext`；声明仅指定允许的重组边界，不证明其业务语义。
- 掩码域：每行 `bool_share0:布尔` 或 `arithmetic_value:算术`，用于 T08 诊断。

无法确认时留空，先看诊断缺项。不能为了消除提示随意指定份额或随机输入。候选可以未改善、功能失败或形式超时，仍能查看和导出；是否接受由实测门槛决定。默认保持接口、复位、完成时刻和目标文件范围。



## 证据范围

新增八类仍属有条件实验能力。窄位宽 gadget、用户提供的随机资源和份额声明都有前提；RTL 结构和切换活动改善不构成门级、毛刺或芯片物理安全证明。候选生成、目标评级、整体验收与导出能力分开解释，见[结果判读](ACCEPTANCE_CONTRACT.md)。
