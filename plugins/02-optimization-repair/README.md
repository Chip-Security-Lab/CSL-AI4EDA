# Optimization & Repair Plugin

**Address side-channel and timing issues in RTL.**

[Home](../../README.md) · [Plugin directory](../README.md) · [Framework](../../docs/ARCHITECTURE.md)

The Optimization & Repair Plugin groups **side-channel + timing repair** capabilities within the optimization and refinement stage of the design flow.

## Scope

- Identifying the relevant side-channel or timing concern and design constraints.
- Reviewing repair or refactoring candidates.
- Assessing proposed changes using the appropriate hardware analysis and verification workflow.

## Documentation entry

This first publication records the plugin's scope and its place in the design flow. Installation, supported inputs, executable usage and measured validation details will accompany the implementation release. This directory contains documentation only.
