# CSL_HDLGen Offline Demos

Double-click an HTML file to open it in a browser. No installation, Python, model API, database service, or internet connection is needed.

- **CSL_HDLGen-General-Demo.html:** a CSR access-control example adapted from PowerSecV. Click **Run demo**, then optionally **Optimize power** to view the second reference.
- **CSL_HDLGen-FSM-Demo.html:** a regular FSM example.
- **CSL_HDLGen-FSM-Unreachable-Demo.html:** an FSM example with original and proposed function-corrected code versions.

Review **Code → Knowledge → Security report**. Use the version selector when available, choose Chinese or English at the top, and click **Open as file** to download the selected `.v` file. Keep the HTML files together to switch modes.

These are fixed examples. Custom generation requires the VS Code extension and a configured model. Opening a demo does not run model generation or HDL verification, and the power reference includes no power measurements.
