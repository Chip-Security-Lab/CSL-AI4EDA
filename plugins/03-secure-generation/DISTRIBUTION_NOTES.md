# Distribution and attribution status

These packages contain readable Python, JavaScript and Tcl runtime code and a security-knowledge database. Packaging does not make the implementation inaccessible.

The supplied generation materials do not include a standalone complete LICENSE. No new blanket license is granted by this publication. Distribution terms and attribution for the implementation, adapted PowerSecV/SecFSM knowledge, paper-derived CSR references, recorded model outputs, interface capture and demos remain pending maintainer confirmation.

The CSR examples name their paper source and explicitly record static-only, untested status. Saved FSM files retain their original generation/version and finite verification provenance; they are not newly verified by this refresh.

The tested VS Code 0.3.16 package is copied byte for byte. The unchanged Vivado companion and examples ZIP are carried forward. The separate demos ZIP contains the three updated offline HTML previews with their usage notes. Complete development trees, local settings, credentials and test artifacts are outside this distribution.
